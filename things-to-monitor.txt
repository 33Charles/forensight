1️⃣ Authentication & Access

Failed login attempts (brute force) – SSH, FTP, sudo attempts, RDP if applicable.

Successful logins – alert for logins at unusual times or from unusual IPs.

Privilege escalation attempts – sudo failures, setuid binaries execution.

Account creation/deletion – new users added or removed.

Unauthorized file access – attempts to read /etc/shadow, logs, or sensitive files.

2️⃣ File & System Integrity

File changes – using tools like AIDE or Python scripts to detect modifications.

New executables – binaries appearing in /tmp or other suspicious locations.

Config tampering – /etc/ssh/sshd_config, /etc/passwd, cron jobs.

Log tampering – deletion or modification of logs.

3️⃣ Process & System Activity

Suspicious processes – unknown binaries running, especially in /tmp or /dev/shm.

Unexpected network connections – high-volume traffic, unusual ports.

High resource usage – spikes in CPU/memory/disk (could indicate crypto-mining or DDoS).

New services/daemons – unexpected daemons or systemd units.

4️⃣ Network Monitoring

Port scans – multiple ports hit by same IP in short time.

DDoS spikes – unusually high packet/sec or connection/sec.

C2 (Command & Control) patterns – HTTP POST to unknown IPs, beaconing traffic.

Suspicious protocols – ICMP floods, unusual UDP traffic, TOR traffic.

5️⃣ Log & Event Monitoring

Syslog / journalctl – monitor for error patterns, failed services, or unusual events.

Application logs – e.g., web servers, database logs.

Security alerts from other tools – like SELinux, AppArmor, auditd.

6️⃣ Indicators of Compromise (IoCs)

Known malware signatures

Blacklisted IP addresses

Malicious domains

Hashes of malicious files
